# orbit. — Growth OS brand book

## Positioning
Agentic go-to-market infrastructure for focused growth teams. Calm, intelligent, and always in motion.

## Logo
The orbital spark represents a growth loop that keeps moving: discover, engage, learn, repeat. Ring mark: `public/brand/orbit-mark.svg` (transparent, for light surfaces), `orbit-app-icon.svg` (ink tile, app icon and workspace switcher), `orbit-favicon.svg`. Wordmark is `orbit.` in lowercase with a violet dot, tagline `GROWTH OS` tracked uppercase. In code use `<OrbitMark/>`, `<AppIcon/>` and `<Brand/>` from `components/orbit`.

## Color system
- Ink `#171723` — primary text and dark theme surface
- Orbit violet `#6358E8` — primary action and brand anchor
- Lavender `#EEEDFF` — selected states and soft surfaces
- Sky `#4E9BE9` — data and pipeline accents
- Coral `#EC7560` — notifications and attention states
- Growth green `#32AD70` — positive metrics and live status
- Warm orange `#EB9944` — secondary emphasis

## Typography
Use Inter (or system UI fallback) for English. Pair with a modern Arabic sans such as IBM Plex Sans Arabic or system Arabic for RTL. Headings are tight and semibold; data labels are small, uppercase, and tracked.

## UI rules
14px card radius, 1px low-contrast borders, soft shadows, violet reserved for action/selection, and generous whitespace. Icons use Lucide at 16–18px with 1.8px stroke.
